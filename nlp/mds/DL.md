# 过拟合和欠拟合
    1、定义，原因
    过拟合，指的是训练数据上表现很好，但测试数据集上表现很差
    欠拟合，模型过于简单，导致学不到本质

    2、解决办法
    过拟合： 扩增数据集、l1，l2，dropout正则，early-stop
    欠拟合： 增加模型复杂度，增加神经元数量、增加特征工程（有效特征）

# 梯度消失和梯度爆炸
一、梯度消失（Vanishing Gradient）
    定义：
        梯度消失是指在深度神经网络的反向传播过程中，梯度值随着层数的增加而逐渐变得非常小，甚至接近于零。这导致靠近输入层的参数更新非常缓慢，训练过程变得极其缓慢甚至停滞。
    原因：
        激活函数的饱和性：如Sigmoid和Tanh激活函数，在输入值较大或较小时，其导数趋近于零。
        深层网络： 梯度在反向传播过程中经过多层链式相乘，导致梯度逐渐减小。
        权重初始化不当：权重初始化过小会导致信号在前向传播中衰减，进而使梯度在反向传播中也迅速减小。
    解决方法：
```bash
        使用ReLU及其变体：ReLU激活函数在正区间梯度为1，避免了梯度消失问题。其变体如Leaky ReLU、PReLU等可以进一步解决ReLU的“死亡神经元”问题。
        批量归一化（Batch Normalization）：通过规范化每一层的输入数据，保持梯度的稳定性，减少梯度消失。
        合适的权重初始化：如Xavier初始化（适用于Sigmoid和Tanh）和He初始化（适用于ReLU），可以避免梯度消失。
        残差网络（Residual Networks）：通过跳跃连接让梯度能够直接跳过某些层传播，避免梯度消失。
        预训练加微调：先进行无监督逐层预训练，再进行有监督微调，减少梯度消失的影响
```

二、梯度爆炸（Exploding Gradient）
    定义：梯度爆炸是指在反向传播过程中，梯度值随着层数的增加而迅速增大，导致模型参数更新过于剧烈，甚至出现数值溢出（NaN）。
    原因：
        深层网络：梯度在反向传播过程中经过多层链式相乘，导致梯度逐渐增大。
        激活函数的选择：如ReLU在输入非常大时可能导致梯度过大。
        权重初始化不当：权重初始化过大可能导致梯度在反向传播时迅速增大。
        学习率过高：过高的学习率会使模型在更新参数时过于激进，加剧梯度的波动。
    解决方法：
```bash
        梯度裁剪（Gradient Clipping）：通过限制梯度的最大值，避免梯度过大。例如，可以将梯度的L2范数裁剪到一个预定的阈值。
        合适的权重初始化： 如Xavier初始化和He初始化，可以避免梯度爆炸。
        降低学习率：使用较小的学习率可以有效防止梯度爆炸。
        使用规范化技术：如批量归一化（Batch Normalization）和层归一化（Layer Normalization），减少梯度的不稳定性。
        权重正则化：通过在损失函数中加入正则化项，限制权重的大小，避免梯度爆炸
```

    4、如何选择parallel_gen正则化l1，l2？
        如果数据集特征较多且大部分特征不重要，L1正则化更适合，因为它可以自动进行特征选择。
        如果数据集特征之间存在多重共线性，L2正则化更合适，因为它可以平衡特征的影响力

    5、为什么cv 用BN，NLP 用ln？！
        数据结构差异：
            计算机视觉处理的是图像数据，具有固定的空间结构和明确的通道分离，适合BN，因为它对每个通道的批量数据进行标准化，从而稳定训练过程。
            自然语言处理处理的是序列数据，每个样本的特征需要全局标准化，LN更适合，因为它对每个样本的所有特征进行处理，不依赖批量大小。
        批量大小的影响：
            CV任务通常使用较大的批量，BN能够稳定计算统计量，效果显著。
            NLP任务常因内存限制使用较小批量，BN效果可能不稳定，而LN不依赖批量大小，表现更佳。
# 优化器
    1、优化器的作用
    2、优化器过程
    Momentum:
        优点：相较于普通的SGD，Momentum在更新过程中考虑了之前梯度的累积，从而可以加速收敛，减少震荡。
        缺点：对超参数（如动量系数）比较敏感。
        适用场景：适用于复杂的优化问题，特别是在非凸函数的训练中。
    Adagrad
        优点：自动调整学习率，稀疏数据的特征更为显著。
        缺点：随着训练进程的进行，学习率会迅速降低，可能导致过早收敛。
        适用场景：适用于稀疏数据或者特征尺度差异较大的任务，如NLP或推荐系统中的问题。
    RMSprop:
        优点：结合了Adagrad的优点，通过引入滑动平均来平滑学习率，避免了学习率过早下降的问题。
        缺点：同样需要调节超参数。
        适用场景：在处理非平稳目标（如RNN训练）时，表现优越。
    Adam
        优点：结合了Momentum和RMSprop的优点，能够自适应调整每个参数的学习率，通常表现出色。
        缺点：在某些问题中，可能导致训练不稳定，尤其是当超参数选择不当时。
        适用场景：广泛应用于各类深度学习任务，尤其是在处理复杂模型和大规模数据集时非常有效。
